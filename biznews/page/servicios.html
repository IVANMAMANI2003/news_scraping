Planes para Usuarios Registrados

Acceso a funcionalidades avanzadas: búsqueda avanzada, API REST y noticias procesadas con IA

Información Importante sobre Acceso
  • Búsqueda Avanzada: Disponible para todos los usuarios autenticados (incluyendo plan FREE). Permite filtrar por múltiples criterios: palabras clave, fuente, categoría, fecha, año, mes, día de la semana, etc.
  • Noticias con IA: Solo disponible para usuarios con plan Enterprise (y administradores). Incluye procesamiento inteligente de contenido, identificación de párrafos relevantes y análisis de relevancia usando modelos de lenguaje avanzados.
  • Servicio Público: Acceso gratuito sin registro al sitio web, búsqueda básica y reportes públicos.
